# Mini Americano de Pádel 🎾

Aplicación web ligera para organizar y anotar torneos tipo *Mini Americano* de 4 parejas.  
Funciona directamente desde Safari o cualquier navegador moderno, incluso sin conexión.

## ⚙️ Características
- 🎨 Fondo oscuro y diseño adaptable a iPhone.  
- 💾 Guarda automáticamente los resultados en el navegador (usa localStorage).  
- 📊 Muestra tabla de posiciones en tiempo real (GF, GC, Dif, Puntos).  
- ⬇️ Permite descargar los datos en formato CSV.  
- 🧹 Botones para reiniciar o borrar datos con un solo toque.  
- 🧭 Funciona sin conexión (instalable como app desde Safari → “Añadir a pantalla de inicio”).

## 📍 Cómo usarla
1. Abre [https://jep61.github.io/Mini-Americano-de-Padel/](https://jep61.github.io/Mini-Americano-de-Padel/).  
2. Edita los nombres de las parejas.  
3. Anota los *games* ganados en cada partido.  
4. Usa **Recalcular** para actualizar la tabla.  
5. El sistema guarda automáticamente los datos, incluso si cierras el navegador.  

## 📁 Archivos principales
- `index.html` — estructura principal del marcador.  
- `style.css` — diseño visual (modo oscuro incluido).  
- `app.js` — lógica del torneo y almacenamiento local.  
- `manifest.json` — configuración de la app para modo instalable.  
- `icon.png` — ícono para pantalla de inicio.
